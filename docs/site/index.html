KEEP THE FIGHT IN VIEW

Your DPS, in sight.

Switch to compact view for the whole party’s DPS, target and timer in a small window that stays above your game.

  • Place it where you want. Drag the DPS header to move the meter.
  • Choose your opacity. Left-click the percentage dropdown to select 30–100%. Your compact setting is remembered.
  • Return to full view. The restore icon brings back 100% opacity and turns always-on-top off.

Capture → compact/restore → share. The buttons keep their order in both views. Use windowed or borderless game mode.

FOCUS ON THE FIGHT

The numbers your party needs.

One window, the whole party, and a target selector. Capture keeps running while you explore the results.

01

Your party, together

See up to five detected members, including idle teammates. Unrelated nearby players stay excluded.

02

Damage in context

Compare DPS and each player’s share of captured party damage. See item level and combat power when available, or filter to one target.

03

Start with one button

Adapter and ports are selected automatically. Your name is detected from game traffic. Start capture, then teleport once to refresh your identity.

04

Automatic encounters

Timing begins with party damage. Pick a target and fight from one dropdown. Recorded contributions stay visible after leaving party. Copy the full chart with the share icon. Both views use direct controls without an options menu.

05

Know when a target falls

A recent positive-to-zero HP update marks a target defeated. Disappearing from view alone isn’t treated as death.

06

A compact combat view

Keep party DPS, target and timer above your game in windowed or borderless mode. Drag the DPS header, select opacity with a left click, and restore full view at 100% opacity with always-on-top off. Window preferences are remembered locally.

GET STARTED

A few minutes to your first capture.

Install the two prerequisites once. AionFlex is not required.

  1. 1

    Install .NET 8 Desktop Runtime

    Choose the Windows x64 Desktop Runtime. You don’t need the developer SDK to run the meter.

    Get the runtime ↗
  2. 2

    Install Npcap

    Npcap provides local packet capture. If the app reports a missing wpcap.dll, enable WinPcap API-compatible mode in the installer.

    Get Npcap ↗
  3. 3

    Extract, launch, capture

    Extract the entire release ZIP to a writable folder. Open LocalDpsTracker.exe, enter the game, and click the play icon beside the encounter timer.

    Get the latest release ↗

Name not detected? Keep capture running and teleport once so the server resends your character identity. Opening equipment does not refresh it. Detected names are remembered locally across updates.

A FEW DETAILS

Before your first run.

How are encounter time and DPS calculated?

The first verified party hit starts an encounter. It finishes after 15 seconds without damage, including that ending grace period in elapsed time and DPS. Long boss-phase gaps can split a fight. Target filters share the encounter clock; a defeated target doesn’t automatically end the whole encounter.

Why might a target’s name be unknown?

The app includes 6,084 English enemy names for offline use. Keep capture running and teleport once to receive NPC spawn mappings. A target can still be unknown if its spawn message was missed or its template is absent from the catalog. An optional local target-names.json can override or add names. Read the catalog instructions and attribution.

Does the app send my data anywhere?

The app has no telemetry, accounts, or automatic upload path. It remembers character names and window preferences locally. Encounter history stays in memory; chart sharing copies an image to your clipboard. This website also has no analytics, external fonts, or tracking scripts.

What are the current limitations?

This is a working prototype, not an independently verified damage benchmark. Game updates can change packet layouts. Mid-instance capture may miss identity or spawn data, distant damage is unavailable when the server doesn’t send it, and unsupported party layouts are excluded. Pets and relay traffic remain provisional. See the known limits.

Can I inspect, modify, or contribute to it?

Yes. The original source is MIT licensed, with build instructions and offline tests. Contributions that improve decoding, reliability, or the interface are welcome. Read the contributing guide.
